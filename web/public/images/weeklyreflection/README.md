# Weekly Reflection backgrounds

Drop background images for the Weekly Reflection feed item and thread page in
this folder. Each weekly post takes the next image in rotation (the one used
least recently), so a handful of images is plenty.

- Formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
- Size: about 1600px wide, ideally under ~400 KB each (these load in the feed)
- Pick calm images with room for text (sky, water, texture, soft blur). The
  quote is overlaid in white on a dark gradient, so very bright or busy photos
  hurt readability
- Only use images we have the right to use
- A new image takes effect after the next deploy (this folder ships in the image)
- If the folder has no images, the post falls back to the normal look
